# EduPath - Educational Guidance Website

## About the Project

EduPath is a beginner-friendly educational guidance website
designed to help students explore learning opportunities,
discover technical courses and understand possible career paths.

## Features

- Professional homepage
- Course cards and categories
- Course search
- Category filtering
- Favourite course saving
- Smart course finder quiz
- Career roadmap
- Contact form validation
- Responsive website design

## Technologies Used

- Python
- Flask
- HTML5
- CSS3
- JavaScript
- Git and GitHub
- Render
